# Инструкция: как создать поездку

**Проект:** `priyut-coordination-bot`  
**Версия документа:** 1.0  
**Для кого:** администраторы приюта / фонда

---

## 1. Кто может создавать поездки

Создавать поездки может только **администратор**, чей Telegram ID добавлен в белый список.

Если команда `/new_trip` не работает или бот отвечает, что доступ запрещен:

- убедитесь, что вы используете правильный Telegram-аккаунт;
- обратитесь к техническому администратору, чтобы ваш Telegram ID добавили в белый список.

---

## 2. Команда для создания поездки

Откройте чат с ботом и отправьте:

```text
/new_trip
```

## 3. Шаги создания поездки

### Шаг 1. Куда нужно отвезти животное

**Цель:** Сбор информации о конечной точке маршрута (целевое учреждение, клиника или конкретный адрес назначения).

##### Интерфейс взаимодействия (Сообщение от бота):
Бот отправляет администратору текстовое сообщение:
```text
Куда нужно отвезти животное?
(укажите клинику и адрес)
```
Пример ответа:
```text
ВетКлиника «Друг», ул. Ленина 5
```
