priyut-coordination-bot

Telegram-бот для координации автоволонтёров приюта.

## Возможности

- Регистрация волонтёров с согласием на обработку ПДн.
- Создание поездок администратором.
- Отклики волонтёров.
- Подтверждение исполнителя администратором.
- Отмена и перенос поездок.
- Напоминания за 24 часа и за 2 часа.
- Двухэтапное завершение поездки.
- Удаление персональных данных по запросу.

## Технологии

- Java 25
- Spring Boot
- PostgreSQL 15
- Gradle Kotlin DSL
- Docker
- Testcontainers
